## Day 1 - Javascript 기초 지식

### 1) 자바스크립트란?

- 자바스크립트는 웹페이지에 반응성을 추가하기 위해 만들어진 언어이다.
- 자바스크립트는 인터넷의 발전에 따라 폭팔적으로 성장하였다.
- 프론트엔드에서 사용할 수 있는 언어는 자바스크립트가 “유일”하다.
  - 2022년 6월 12일 기준 WASM이라는 기술로 웹에서 자바스크립트 이외의 언어를 구동하는 것이 가능해졌으나 이는 자바스크립트로 제작하기 어려운 컴퓨팅 파워가 많이 필요한 서비스에 제한적으로 사용되고 있다.
  - 2022년 6월 12일 기준 pyscript가 개발되어 파이썬을 웹을 제작하는데 사용할 수 있게 되었다. (알파 버전) ([https://pyscript.net](https://pyscript.net/))
- 현재 자바스크립트는 매우 다양한 분야에 사용된다.
  1. 웹페이지 제작
  2. iOS, Android 앱 개발 (React Native [https://reactnative.dev/](https://reactnative.dev/))
  3. 데스크탑 앱 개발 (Electron [https://www.electronjs.org/](https://www.electronjs.org/))
  4. 인공지능 개발 (Tensorflow [https://www.tensorflow.org/js?hl=ko](https://www.tensorflow.org/js?hl=ko))
  5. 3D 오브젝트를 활용한 웹페이지 개발 (Three.js [https://threejs.org/](https://threejs.org/))
  6. 백앤드 개발(Node.js [https://nodejs.org/ko/](https://nodejs.org/ko/)) (Express [https://expressjs.com/](https://expressjs.com/))
  7. 머신러닝 학습 (ml5.js [https://ml5js.org/](https://ml5js.org/))
- 모든 브라우저에는 자바스크립트가 기본으로 설치되어 있다. (따로 설치할 필요 없다.)

### 2) 자바스크립트 체험

자바스크립트는 아무 세팅도 하지 않은채 우리 컴퓨터에서 실행할 수 없습니다. 그러나 다른 프로그래밍 언어와는 다르게 자바스크립트는 웹페이지를 위해 만들어진 언어이기 때문에 모든 브라우저에서 실행할 수 있습니다. 우선 자바스크립트 코드를 실행하기 위해 자신이 사용하는 브라우저를 실행합니다.

브라우저가 열리면 개발자 도구를 실행합니다.

- 윈도우 : 키보드 우측 상단의 F12를 누르거나 Ctrl + Shift + C를 입력
- 맥 - 사파리: 좌측 상단 메뉴막대에서 개발자용 메뉴가 보이지 않는 경우 Safari > 환경설정을 선택하고 고급을 클릭한 다음, ‘메뉴 막대에서 개발자용 메뉴 보기’를 선택하세요.
- 맥 - 사파리 외 : Ctrl + Shift + C를 입력

개발자 도구가 열리면 개발자 도구 탭에서 ‘콘솔’ 또는 ‘Console’을 선택합니다.

### 자바스크립트 파일 실행

자바스크립트 파일은 단독으로 실행할 수 없습니다. 자바스크립트는 웹페이지를 위해 설계된 언어로 처음부터 HTML과 함께 쓰일 목적으로 계발되었습니다. 그래서 자바스크립트 파일은 단독으로 실행 불가합니다. (단, 이후에 다룰 Node.js에서는 단독으로 실행 가능합니다.)

자바스크립트 파일을 실행시키기 위해서는 HTML 파일을 생성하고 HTML 파일에 자바스크립트 파일을 연결한 후 HTML 파일을 실행시키는 방식으로 자바스크립트를 실행해야 합니다.

1. HTML 파일을 생성합니다.
2. HTML 파일에서 ! 를 입력하면 아래와 같이 나오는데 자동완성이 보이면 엔터를 눌러 HTML 파일의 기본 틀을 생성합니다.

![Untitled](/images/posts/javascript-basic/Untitled%203.png)

1. 자바스크립트 파일을 HTML 파일을 연결하기 위해 <body> </body> 태그 안에 아래 태그를 입력합니다.

```jsx
<script src="파일명.js"></script>
```

ex)

```jsx
<script src="app.js"></script>
```

HTML파일을 실행시키면 아까 브라우저 콘솔에 입력했던 것처럼 알림이 나오게 됩니다.

cf) HTML 파일 실행시키는 방법

1. 파일 관리자(파인더)에서 프로젝트 파일 위치로 이동 후 HTML 파일을 우클릭 후 브라우저로 실행
2. VS Code에서 F5 키를 눌러 실행시킨다.
3. VS Code에서 파일을 드레그 해서 브라우저 탭에 넣는다. (사파리는 불가)

## Day 2 - 자바스크립트 데이터 종류, 변수

### 프로그래밍 언어 기본 상식

프로그래밍 언어를 배우며 알아야 하는 기본 상식

1. 컴퓨터는 우리 코드를 위에서 아래로 차래대로 읽는다.
2. 코드가 작동하지 않는것은 우리 잘못이지 컴퓨터 잘못이 아니다.
3. 코딩 초보의 실수 중 80%는 오타이다.
4. 오류에 대한 모든 답은 구글에 있다.
5. 컴퓨터는 계산기이다.

### 자바스크립트 언어 기본 상식

자바스크립트 코드에서 코드 마지막 줄에 세미콜론 (;) 이 붙은것을 볼 수 있습니다. 세미콜론은 코드의 끝을 구분하기 위해 사용하지만 세미콜론을 붙이지 않아도 코드는 실행됩니다. 따라서 세미콜론은 붙여도 되고 안붙여도 되지만 관례상 이 강의에서는 모든 코드에 세미콜론을 붙입니다.

### 자바스크립트 기본 데이터

1. 정수 (integer)

   정수는 자바스크립트에서 int 라고 표현하며 정수를 표현하는 방법은 그냥 정수를 입력하면 됩니다.

   ```jsx
   3;
   ```

2. 실수 (float)

   자바스크립트에서 실수는 float 라고 표현하며 정수를 표현 하는 방법 또한 정수 표현과 같이 그냥 실수를 입력하면 됩니다.

   ```jsx
   3.1415926535897932;
   ```

3. 문자 (string)

   자바스크립트에서 문자는 str 이라고 표현하고 문자를 표현하기 위해선 ‘’ 또는 “” 안에 문자를 넣어 표현합니다.

   ```jsx
   "Beatus 화이팅";
   "app team 화이팅";
   ```

   문자에서 주의해야 할 점은 문자를 표현하기 위해 “” 나 ‘’를 사용하는데 두개를 같이 사용할 수는 없습니다.

   ```jsx
   'Hello javascript"
   ```

### console.log()

자바스크립트에서 문자나 수를 출력하는 방법에는 여러가지가 있습니다. 우리는 그 중에 alert을 사용하여 브라우저에서 우리가 원하는 값을 출력해보았습니다. 그러나 우리는 경고창(alert)을 띄우는것 말고도 다른 방식으로 출력할 수도 있습니다. 그 방법 중 가장 많이 사용하는 방법이 브라우저 콘솔창에 출력하는 것입니다.

1. 브라우저에서 우리 프로젝트 파일에 있는 index.html 파일을 열고 해당 탭에서 개발자 도구를 실행합니다.
2. 개발자 도구에서 콘솔 탭으로 이동합니다.

기존의 자바스크립트 코드를 모두 지우고 아래 코드를 예제로 입력합니다.

### 변수

변수는 데이터를 저장할 수 있는 공간입니다. 변수는 매우 자주 사용하므로 정확히 알아둘 필요가 있습니다.

변수 선언

파이썬과는 다르게 자바스크립트에서는 변수를 생성할 때 변수를 만든다고 선언해줘야 합니다. 변수 선언은 다음과 같이 합니다.

```jsx
const 변수 이름 = 변수에 저장할 값;
```

<aside>
💡 이제부터 한글로 된 텍스트는 모두 자신에 맞게 변형해야 하는 부분입니다!

</aside>

위에 코드는 변하지 않는 값을 선언하는 코드입니다. 맨 앞에 나오는 const는 변경할 수 없는 변수를 선언할 때 사용하는 코드입니다. 변수 타입 설정 코드 뒤에는 한 칸 뛰고 변수의 이름을 설정해줍니다. 등호 (=) 뒤에는 변수에 저장할 값을 작성합니다.

ex)

```jsx
const myName = "Hyunwoo";
const myAge = 18;
```

### 변수명 짓는법

1. 변수명 안에는 띄어쓰기가 포함될 수 없다.
2. 변수명은 알파벳, 한글, 한자 등 모든 문자가 가능하다.
3. 변수명 안에 숫자를 사용할 수 있지만 변수명은 숫자로 시작할 수 없다.
4. 변수명 안에 특수문자를 사용할 수 있지만 특수문자로 변수명을 시작할 수 없다.

<aside>
💡 자바스크립트에서 변수의 이름을 지정할 때는 규칙이 있습니다. 자바스크립트 변수명은 관례상 띄어쓰기 다음에 있는 문자를 대문자로 바꿔 표현합니다. 이 규칙은 관례이기 때문에 반드시 따라야 하는것은 아니지만 다른 사람과 코드를 공유할 때 코드 이해에 도움이 될 수 있습니다.

</aside>

ex)

```jsx
const thisIsRuleOfNamingVariable = "Nice!";
```

### 변수 종류

1. const

   const는 자바스크립트의 기본 변수입니다. const로 생성한 변수는 변경할 수 없습니다. 그래서 코드 안에서 절대 바뀌지 않아야 할 변수를 생성할 때 사용합니다. 그러나 보안상의 이유로 변수를 자주 바꿔야 하는 경우를 제외하고는 항상 const를 사용합니다.

   ex)

   ```jsx
   const thisValueCanNotBeChanged = 2022;
   ```

2. let

   let은 자주 변경해야하는 변수를 선언할 때 사용하는 코드입니다. let으로 변수를 선언하는 것이 편하다고 느낄 수 있지만 보안상의 이유로 let을 사용하는 것은 최대한 줄이는것이 좋습니다.

   ex)

   ```jsx
   let thisValueCanBeChanged = 228; //변수 선언

   thisValueCanBeChanged = 334; //변수 값 변경
   ```

3. var

   var은 let과 비슷한 형태의 변수 종류입니다. 따라서 var로 선언한 변수는 쉽게 바꿀 수 있습니다. 그러나 var은 오래된 자바스크립트 코드에서 사용된 변수의 종류로 현제는 많이 사용되지 않습니다. 따라서 절대 var 을 사용해서 변수 선언을 하지 마세요! 오래된 자바스크립트 책을 보면 var로 변수선언하는 것을 많이 볼 수 있습니다.

   var을 사용하지 말라는 의미로 예시도 보여주지 않겠습니다.

### 연산자 (더하기, 빼기, 곱하기, 나누기, 나머지, 제곱...)

자바스크립트에서 사용하는 연산자는 파이썬과 매우 동일합니다. 파이썬 연산자를 알고 있다면 넘어가도 좋습니다. (사실 거의 모든 프로그래밍 언어의 연산자는 동일합니다.)

| 종류            | 자바스크립트 연산자 |
| --------------- | ------------------- |
| 더하기          | +                   |
| 빼기            | -                   |
| 곱하기          | \*                  |
| 나누기          | /                   |
| 나누기 (나머지) | %                   |
| 제곱            | \*\*                |

수학과 마찬가지로 소괄호 안에 있는 식을 우선으로 계산합니다.

ex)

```jsx
console.log(3 + 7); //출력값: 10
console.log(10 - 4); //출력값: 6
console.log(4 * 8); //출력값: 32
console.log(13 / 5); //출력값: 2.6
console.log(13.0 / 5); //출력값: 2.6
console.log(13 % 5); //출력값:  3
console.log(2 ** 3); //출력값: 8
```

문자의 연산

문자 또한 연산자를 이용하여 문자를 더할 수 있습니다.

ex)

```jsx
console.log("hello" + "Beatus"); //출력값: helloBeatus
```

### function (함수)

함수는 코드에서 반복적으로 사용하는 코드를 간단히 사용할 수 있도록 툴을 만드는 것입니다. React 에서 HTML을 반환하기 위해 사용하는 것도 함수입니다. 함수는 정말 많이 사용하는 것이기 때문에 잘 배워두길 바랍니다.

- function 선언

  자료를 사용하는 함수는 다음과 같이 선언합니다.

  ```jsx
  function 함수이름(사용할 자료의 변수 이름){
  ```

  ### return (전달)

  함수 안에서 구한 값을 함수 밖에서 사용하고 싶다면 어떻게 해야할까요? 함수 안에 있는 변수는 독립적이기 때문에 함수 안에서 변수 안의 값을 바꾸더라도 함수 밖에서는 해당 변수를 사용할 수 없습니다. 따라서 우리는 함수 안에서 구한 값을 함수 밖으로 꺼내줘야합니다. 이때 사용하는 것이 바로 return 입니다.

  return을 사용하는 방법은 매우 간단합니다. 함수 끝에서 밖으로 꺼내고 싶은 변수를 return 끝에 적어주기만 하면 됩니다.

  ```jsx
  function addTwoNum(a, b) {
    const sum = a + b;
    return sum;
  }
  ```

  위에 코드를 보면 addTwoNum 이라는 함수는 두개의 자료를 받아 더하고 더한 값 sum을 함수 밖으로 꺼내고 있습니다.

  ```jsx
  console.log(addTwoNum(4, 9));
  ```

  위에 코드를 실행하면 13이 출력됩니다. 왜냐하면 addTwoNum이라는 함수가 전달받은 두 자료를 더하고 이를 함수 밖으로 빼주었기 때문입니다. 간단히 생각하면 return을 통해 addTwoNum(4, 9)라는 함수가 14로 대체되었다 라고 생각하면 쉽습니다.

  ```jsx
  console.log(addTwoNum(4, 9));

  --> console.log(13);
  ```

## Day - 6 Event

자바스크립트 이전에도 설명했다시피 웹 페이지를 위해 만들어진 언어입니다. 따라서 웹페이지에서 유용하게 사용할 수 있는 event 라는 것이 있습니다. event 는 HTML 파일에서 특정 한 일이 일어나면 실행하는 자바스크립트를 지정하기 위해 사용합니다.

HTML파일에서 일어나는 이벤트를 가져오기 위해선 addEventListener() 함수를 사용합니다.

HTML 파일에서 이벤트를 가져오기 위해선 해당 이벤트가 일어나는 HTML 코드를 가져오고 addEventListener를 추가해야 합니다.

```jsx
가져온 HTML 코드를 가져온 변수.addEventListener("이벤트 종류", 이벤트가 일어나면 실행할 함수);
```

ex)

```jsx
const element = document.getElementById("main-title");

function sayHello() {
  alert("Hello");
}

element.addEventListener("click", sayHello);
```

위 코드를 보면 main-title이라는 아이디를 가진 HTML 코드를 가져온 후 element 라는 변수에 저장합니다. Hello 라는 문구로 경고창을 보내는 함수를 선언하고 클릭 이벤트를 감지하는 addEventListener를 추가하여 main-title을 아이디로 가진 HTML 코드 부분이 클릭되면 sayHello 함수가 실행됩니다.

이벤트의 종류가 click 말고도 여러가지 있습니다. 인터넷에서 찾아보는것을 추천합니다.

### 이벤트 리스너 삭제하기

이벤트 리스너를 통해 유저의 반응에 따라 실행할 함수를 지정할 수 있었습니다. 필요에 따라 이벤트 리스너를 삭제할 수도 있습니다. 이벤트를 삭제하기 위해선 removeEventListener을 통해서 이벤트를 삭제할 수 있습니다. 주의할 점이 있다면 소괄호 안에 삭제하려는 addEventListener와 똑같이 입력해야 합니다.

```jsx
const title = document.getElementById("title");
function sayHello() {
  alert("Hello Beatus");
}
//이벤트 리스너 생성
title.addEventListener("mouseover", sayHello);

//이벤트 리스너 삭제
title.removeEventListener("mouseover", sayHello);
```

위 코드와 같이 이벤트를 삭제하기 위해선 이벤트 리스너를 등록할 때 입력한 이벤트 종류와 이벤트 발생 시 실행할 함수를 똑같이 설정해줘야 합니다.

## Day 7 - CSS in Javascript

이번 시간에는 자바스크립트로 CSS를 수정하는 방법에 대해 알아볼겁니다. 지금까지 자바스크립트로 HTML 파일을 수정하는 것을 알아보았는데 보통은 HTML 보다 CSS를 수정하는 경우가 많습니다. 자주 사용하는 부분인 만큼 많이 반복하길 바랍니다.

자바스크립트로 CSS를 수정하기 위해선 CSS를 수정하려는 HTML 코드를 불러온 다음 CSS를 수정해야 합니다. 이벤트 리스너 등록을 위해 HTML 코드를 불러온 것 처럼 CSS를 수정하기 위해 HTML 코드를 자바스크립트로 불러와야 합니다.

```jsx
const title = document.getElementById("main-title");
```

위 코드 처럼 title이라는 변수에 HTML 코드를 불러온 다음 title 변수 뒤에 .style 을 붙이면 해당 HTML 코드에 적용된 CSS 를 수정할 수 있습니다.

```jsx
title.style.스타일종류 = 새로운스타일값;
```

위 코드만 보았을 때는 이해가 어려울 수 있으니 글자 색을 바꾸는 코드를 예시로 들어보겠습니다.

```jsx
const nomalText = document.getElementById("paragraph");

nomalText.style.color = "red";
```

위 코드를 보면 nomalText라는 변수에 HTML 코드를 저장한 다음 해당 HTML 코드에 적용된 CSS중 color 값을 “red” 로 변경하는 코드입니다.

style 은 HTML코드에 CSS가 적용되어 있지 않더라도 CSS를 추가하여 적용하기 때문에 CSS파일에 없는 요소를 적용하거나 CSS가 적용되지 않은 HTML코드도 .style을 통해 CSS를 수정할 수 있습니다.

## Day 8 - 자바스크립트로 HTML 코드 생성

지금까지 기존에 생성된 HTML코드를 가져오고 수정하는 방법을 알아보았습니다. 이번 시간에는 자바스크립트로 HTML 코드를 생성하는 방법에 대해 알아보겠습니다.

자바스크립트로 HTML코드를 생성하기 위해선 createElement, appendChild 를 사용해야 합니다.

우선 자바스크립트로 HTML코드를 생성하기 위해선 어디에 HTML 코드를 생성할지 지정해줘야 합니다. HTML 코드에서 코드를 추가할 위치를 지정해주기 위해 자바스크립트로 HTML 코드를 가져와 변수에 저장해줘야 합니다.

```jsx
const 변수이름 = document.getElementById("아이디이름");
```

ex)

```jsx
const list = document.getElementById("myFavList");
```

위와 같은 방법으로 HTML코드를 가져와 변수에 저장을 해준 다음 HTML 태그 중 어떤 태그를 사용하여 코드를 생성할지 지정해줘야 합니다. 이때 사용하는 것이 createElement입니다. createElement는 한 줄의 HTML 코드를 생성합니다. 우리는 createElement로 생성한 HTML 코드를 변수에 저장하여 나중에 appendChild로 HTML 코드에 생성한 코드를 추가할 것입니다.

우선 createElement는 아래와 같은 방법으로 사용합니다.

```jsx
const 변수이름 = document.createElement("HTML태그이름");
```

위에 나오는 HTML태그 이름은 무조건 HTML코드에서 사용하는 태그 이름(ex. h1, span, div, button 등)으로 지정해야 합니다.

ex)

```jsx
const apple = document.createElement("h3");
```

위 처럼 생성한 코드는 우리가 HTML코드 수정에서 배운 방식으로 내용을 추가해줄 수 있습니다.

간단한 예시로 HTML코드 안에 들어가는 문자를 수정해보겠습니다.

```jsx
apple.innerText = "I am CNSA student but I like Apple";
```

이런식으로 생성한 HTML코드 안의 구성요소를 채워주면 됩니다.

생성한 HTML코드를 HTML파일에 추가시키기 위해 appendChild를 사용해야 합니다. appendChild는 우리가 지정한 HTML코드 아래 하위 컴포넌트로 HTML코드를 추가하는 함수입니다. 말로만 하면 어려우니 간단한 예시를 보여드리겠습니다.

아래 예시는 직접 따라해보길 권장합니다.

아래와 같이 index.html 파일을 생성합니다.

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta http-equiv="X-UA-Compatible" content="IE=edge" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <div id="apple"></div>
    <script src="app.js"></script>
  </body>
</html>
```

위에 코드를 보면 body태그 안에 div 태그만 있고 다른건 없습니다. 그리고 div 태그의 아이디가 apple인 것을 볼 수 있습니다. HTML코드에 코드를 추가하기 위해 자바스크립트 파일을 만들어보겠습니다.

```jsx
const loc = document.getElementById("apple"); //코드를 추가할 HTML 코드 가져온 후 변수에 저장
const span = document.createElement("span"); //span 태그를 가진 HTML 코드 생성
span.innerText = "I like Javascript and React JS."; //생성한 span태그 안에 문장 생성
loc.appendChild(span); //가져온 HTML코드의 하위 컴포넌트로 생성한 코드 삽입
```

위 코드의 주석에 달려있는 것 처럼 생성할 코드를 집어 넣을 HTML 코드를 가져온 후 HTML코드를 생성하여 지정한 위치이 집어 넣으면 됩니다.

appendChild가 하는 일을 직접적으로 보기 위해 예시를 사용하겠습니다.

자바스크립트를 통해 어떤 HTML코드를 가져오면 다음과 같이 보이는 코드를 가져왔을 것입니다.

```jsx
<div id="box"></div>
```

이렇게 가져온 코드에 appendChild를 통해 생성한 코드를 집어넣으면 다음과 같이 됩니다.

```jsx
<div id="box">
  <span>Hello World</span>
</div>
```

이런식으로 appendChild는 생성한 코드를 가져온 코드의 하위 컴포넌트로 HTML에 추가합니다.

## Day 9 - 브라우저에 데이터 저장하기

웹사이트를 제작하다보면 정보를 저장하고 사용해야 할 때가 있습니다. 만약 백앤드가 있다면 백앤드에 정보를 저장하면 되지만 백앤드 없이도 정보를 저장할 수 있습니다. 정보를 브라우저에 저장할 수 있는데 이 때 사용하는 것이 localStorage입니다. localStorage를 사용하면 브라우저에 텍스트 형태로 저장하여 웹페이지를 나갔다 들어와도 정보를 계속해서 사용할 수 있습니다.

localStorage를 사용하는 방법은 정보를 저장하는 방법과 정보를 가져오는 방법 두가지가 있습니다.

### localStorage로 데이터 저장하는 방법

localstorage로 데이터를 저장하는 방법은 다음과 같습니다.

```jsx
localStorage.setItem("데이터키", 데이터);
```

로컬스토리지에 데이터를 저장히기 위해선 데이터의 키를 정해 데이터를 저장해야합니다. 왜냐하면 데이터 키가 없다면 로컬스토리지에서 데이터를 불러올 때 어떤 데이터를 불러와야 할지 특정하지 못하기 때문입니다.

ex)

```jsx
localStorage.setItem("food", "pasta");
```

이런식으로 데이터를 저장하게 됩니다.

localStorage에서 주의해야 할 점이 있습니다. 맨 처음에 설명했다시피 localStorage는 텍스트 형태로 데이터를 저장합니다. 따라서 자바스크립트에서 사용하는 자료형인 정수, 실수, 배열 등의 자료형을 저장한다고 하더라도 모두 텍스트 형태로 저장됩니다.

```jsx
localStorage.setItem("thisIsArray", ["hello", "world"]);
```

개발자 도구를 열어 콘솔에서 위 코드를 입력해봅니다.

cf) json 형태 데이터

json형태의 데이터는 웹사이트가 백앤드 서버와 통신할 때 사용하는 형식의 데이터로 웹사이트에서 자주 사용하는 데이터 형식입니다. 더 자세한 내용은 인터넷을 참고하세요.


### localStorage에서 데이터 불러오는 방법

로컬 스토리지에 저장한 데이터를 불러오기 위해 localStorage.getItem 을 사용합니다. 사용방법은 아래와 같습니다.

```jsx
localStorage.getItem("데이터키");
```

로컬스토리지에 저장할 때 사용했던 데이터 키를 소괄호 안에 넣어 데이터를 가져올 수 있습니다.

ex) (콘솔에 입력하세요.)

```jsx
localStorage.setItem("food", "pizza");
```

위 코드를 입력하여 로컬 스토리지에 데이터를 저장합니다.

```jsx
localStorage.getItem("food");
```

### 데이터 타입 보존해서 데이터 불러오기

만약 데이터를 저장할 때 JSON.stringify를 통해 데이터 타입을 보존하여 데이터를 저장하였다면 데이터를 불러오는 것은 텍스트 타입과 똑같지만 불러온 데이터를 사용할 때는 처리 과정이 필요합니다.

데이터를 처리할 때는 JSON.parse() 함수를 사용합니다.

```jsx
localStorage.setItem(
  "myFavfood",
  JSON.stringify(["학교 조식", "학교 중식", "학교 석식"])
);
```

데이터를 위와 같이 저장하였다면

```jsx
const food = JSON.parse(localStorage.getItem("myFavFood"));
```

이렇게 처리를 한 번 해준 다음

```jsx
alert(food);
```

alert, console.log 등등을 사용해야 합니다. 만약 JSON.parse를 하지 않는다면 원래 자료형이 아닌 텍스트 그 자체로 데이터가 불러와지기 때문에 원래 자료형을 사용할 수 없습니다.

JSON.parse 사용법


## 번외 - 데이터 입력했을때 브라우저가 새로고침 하는 것 막기

웹사이트에서 데이터를 받을 때 엔터 키를 누르거나 버튼을 눌러서 데이터를 입력하는데 이럴 때 브라우저가 새로고침 되는 것을 볼 수 있습니다. 이럴 때는 이벤트 리스너에 등록된 함수가 받는 값을 추가하고 preventDefaule() 함수를 다음과 같이 추가해주면 됩니다.

```jsx
function submit(event){
	event.preventDefault();
	함수 코드...
};
button.addEventListener("click", submit)
```

위와 같이 이벤트 리스너를 통해 함수가 실행될 때 이벤트에 관한 정보를 받기 위해 함수에 입력 값을 하나 추가한 후 입력값에 preventDefaule()함수를 적용시켜 주면 브라우저가 새로고침하는 것을 막을 수 있습니다.
