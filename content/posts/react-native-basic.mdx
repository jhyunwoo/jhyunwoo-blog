# React Native

## Day 1 - React Native란?

### 앱 개발

리액트 네이티브는 iOS와 Android 앱을 한번에 개발할 수 있게 해주는 유니버셜 앱 개발 방식입니다. 우선 네이티브 개발, 유니버셜 개발의 차이점에 대하여 알아보겠습니다.

1. 네이티브 개발
   1. 안드로이드 개발
      1. 프로그래밍 언어: Java, Kotlin
      2. 성능: 매우 빠름
      3. 난이도
         1. Java: 상
         2. Kotlin: 중
      4. 최신 버전 지원: 안드로이드 버전 업데이트에 대한 지원 매우 빠름
   2. iOS 개발
      1. 프로그래밍 언어: Object-C, Swift
      2. 성능: 매우 빠름
      3. 난이도
         1. Object-C: 극상
         2. Swift: 중
      4. 최신 버전 지원: iOS 버전 업데이트에 대한 지원 매우 빠름
2. 유니버셜 개발
   1. React Native
      1. 프로그래밍 언어: Javascript
      2. 성능: 느림
      3. 난이도: React를 배웠다면 하, 안배웠다면 중
      4. 최신 버전 지원: 네이트브 보다 느림
   2. Flutter
      1. 프로그래밍 언어: Dart
      2. 성능: React Native 보다 빠르고 네이티브 보다 느림
      3. 난이도: 중
      4. 최신 버전 지원: 네이티브 보다 느림

네이티브로 개발한다면 빠른 성능과 최신 기술을 사용할 수 있다는 장점이 있지만 서비스를 개발할 때 안드로이드와 iOS 모두 개발해야해서 작업시간이 오래 걸린다는 단점이 있습니다.

유니버셜 개발의 경우 iOS와 Android 앱을 한 번에 개발 할 수 있고 한가지 프로그래밍 언어만 공부해도 된다는 장점이 있지만 네이티브보다 성능이 떨어지고 최신 기술에 대한 지원이 늦다는 단점이 있습니다.

우리는 유니버셜 앱 개발에 가장 많이 사용되는 리액트 네이티브를 사용해보겠습니다.

### React Native

리액트 네이티브는 페이스북에서 개발한 유니버셜 앱 개발 환경으로 iOS, Android, Web, Windows, Mac OS 앱을 개발할 수 있습니다. 자바스크립트를 사용하며 필수적으로 리액트를 사용합니다.

리액트 네이티브를 배우기 전에 리액트를 배우는 것이 맞지만 시간 관계상 리액트를 배울 시간이 없기 때문에 리액트 네이티브를 배우면서 나오는 리액트 개념을 설명하는 방식으로 수업을 진행하겠습니다.

리액트 네이티브에서는 HTML과 비슷한 방식으로 개발하지만 HTML에서 사용하는 태그는 사용할 수 없습니다. 우리가 사용할 수 있는 모든 것은 인터넷에 나와 있습니다. 우리가 앱을 개발하면서 주로 사용할 컴포넌트는 다음과 같습니다.

- 리액트 네이티브 기본 컴포넌트 ([https://reactnative.dev/docs/components-and-apis](https://reactnative.dev/docs/components-and-apis))
- expo 컴포넌트 ([https://docs.expo.dev/](https://docs.expo.dev/))

리액트 네이티브 문서에 기초부터 나와있기 때문에 모르는 것이 있다면 리액트 네이티브 개발자 문서를 찾아보는 것을 추천합니다. ([https://reactnative.dev/](https://reactnative.dev/))

## Day 2 - 리액트 네이티브 개발 환경 구축하기

리액트 네이티브 개발 환경을 구축하는 방식은 크게 두가지가 있습니다. 리액트 네이티브 CLI와 Expo가 있습니다. React Native CLI를 사용하면 안드로이드 개발 환경과 iOS개발 환경을 모두 구축해야 하기때문에 매우 번거롭고 각 디바이스 마다 생기는 오류를 해결하기 어렵습니다. 따라서 우리는 쉽개 개발환경을 구축하고 바로 핸드폰에서 결과를 확인할 수 있는 Expo를 사용하여 개발환경을 구축합니다.

## Day3 - React Native 작동 원리

이번 수업은 실습 보단 이해에 초점을 두고 가벼운 마음으로 읽어도 됩니다.

리액트 네이티브는 안드로이드, iOS앱을 모두 개발해야 하는 번거로움을 없애주는 편리한 앱 개발 환경입니다. React Native를 개발한 페이스북은 어떻게 안드로이드와 iOS를 한번에 개발할 수 있도록 했을까요?

리액트 네이티브는 안드로이드와 iOS를 자바스크립트로 조작하기 위한 환경을 이미 만들어놨습니다. 이러한 환경을 핸드폰 os와 자바스크립트 코드를 연결해주는 브릿지라고 합니다. 페이스북에서 만들어 놓은 환경(브릿지) 위에 우리는 자바스크립트로 기기를 조작만 하면됩니다. 우리가 자바스크립트로 프로그래밍 하면 리액트 네이티브는 우리가 작성한 자바스크립트 코드를 사용하여 핸드폰 화면에 우리가 작성한 코드를 보여줍니다. 이렇게 네이티브 앱 보다 한 단계를 더 거쳐야 하기 때문에 속도가 느려질 수 밖에 없습니다. 하지만 안드로이드와 iOS 앱을 한번에 개발할 수 있다는 것 만으로도 리액트 네이티브를 사용할 이유는 충분합니다.

## Day 5 - React Native 기초

리액트 네이티브는 자바스크립트로 앱을 만들기 때문에 웹과 비슷한 구조로 되어있습니다. 그러나 리액트 네이티브는 절대 웹이 아닙니다. 따라서 웹을 개발하면서 사용했던 지식을 어느 정도는 사용할 수 있지만 모두 사용할 수 있는 것은 아닙니다.

리액트 네이티브 앱을 처음 만들면 기본으로 나와있는 앱 코드에 대해 알아보겠습니다.

```jsx
import { StatusBar } from "expo-status-bar";
import { StyleSheet, Text, View } from "react-native";

export default function App() {
  return (
    <View style={styles.container}>
      <Text>Hello Beatus!</Text>
      <StatusBar style="auto" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: "#fff",
    alignItems: "center",
    justifyContent: "center",
  },
});
```

위 코드를 보면 첫 번째 줄과 두 번째 줄에서 패키지를 가져오고 있는 것을 볼 수 있습니다. 이 두 줄은 리액트 네이티브에서 활용할 컴포넌트를 가져오는 것으로 현재 가져오고 있는 StatusBar, StyleSheet, Text, View는 필수적이기 때문에 절대 지우면 안됩니다. 만약 이 컴포넌트를 사용하지 않는다면 지워도 되긴 합니다.

"export default function"으로 시작하는 함수 안에 쌓여진 코드를 보겠습니다. 우선 export default는 리액트네이티브 코드가 실행될 때 가장 먼저 봐야하는 함수라는 의미 입니다. 그 다음으로 return 안에 있는 코드를 보면 HTML코드와 유사하게 생긴것을 볼 수 있습니다. return 안의 코드가 우리에게 보여지는 부분을 생성합니다. 우리가 코드를 작성할 때는 무조건 View 관련 태그를 사용합니다. VIew 태그는 HTML에서 div 태그랑 비슷하다고 생각하면 됩니다.

리액트 네이티브에서 문자를 사용할 때는 무조건 Text 태그 안에 작성해야 합니다. 만약 Text태그 안에 문자를 작성하지 않았다면 오류가 나게 됩니다.

코드를 보면 StatusBar라는 컴포넌트가 있는데 이 컴포넌트는 우리 휴대폰에서 보이는 시간, 배터리, 와이파이 등 상태 표시 줄을 의미합니다. 기본으로 style이 auto라고 되어있는데 이를 light로 바꾸면 밝은 색으로 상태표시줄이 바뀌는 것을 볼 수 있습니다.

아래 const styles = StyleSheet로 시작하는 코드가 있는데 이는 코드의 스타일을 적용하는 코드입니다. 스타일 코드는 위와 같이 작성하며 CSS와 매우 흡사합니다. 그러나 CSS를 자바스크립트 안에서 작성해야 하기 때문에 - 기호를 사용하지 않고 그 사이 다음 문자를 대문자로 바꾸어 사용합니다.

ex) background-color (CSS에서 사용)

backgroundColor (자바스크립트 안 CSS에서 사용)

### React Native Packages

리액트 네이티브를 활용하여 앱을 만들게 되면 외부 패키지를 많이 사용합니다. Text, View와 같이 리액트 네이티브에서 기본으로 제공하는 컴포넌트도 있지만 로컬 스토리지 저장 등 다양한 기능을 활용하기 위해선 외부 패키지를 사용해야합니다. 기본으로 만들어진 앱에서도 StatusBar 컴포넌트는 외부 패키지인 expo-status-bar를 사용하여 가져온 컴포넌트 입니다.

리액트 네이티브가 처음 만들어졌을 때에는 리액트 네이티브에서 모든 컴포넌트를 제작하였습니다. 그러나 기능이 다양해지면서 리액트 네이티브에서 모든 컴포넌트를 만들기 어려워졌습니다. 그래서 핵심 컴포넌트는 리액트 네이티브에서 만들고 다양한 기능이 있는 컴포넌트는 다양한 개발자가 제작하게 되었습니다.

아래 링크는 패키지를 찾아볼 수 있는 웹사이트 입니다.

- 리액트 네이티브 공식 사이트 ([https://reactnative.dev/docs/components-and-apis](https://reactnative.dev/docs/components-and-apis))
  - 리액트 네이티브에서 제작하는 컴포넌트로 필수적인 컴포넌트만 있습니다.
  - 리액트 네이티브에서 제작함으로 신뢰도가 매우 높습니다.
- Expo 패키지 ([https://docs.expo.dev](https://docs.expo.dev/))
  - Expo에서 제작한 외부 라이브러리로 신뢰도가 높습니다.
- 리액트 네이티브 디랙토리 ([https://reactnative.directory](https://reactnative.directory/))
  - 여러 개발자가 라이브러리를 개발한 것을 공유하는 웹사이트로 다양한 기능의 라이브러리가 있지만 유지 보수가 잘 되지 않는다던가 오류가 있을 수 있습니다.
  - 잘 사용하면 매우 유용합니다

리액트 네이티브 앱을 만들때는 패키지를 잘 사용하는 것이 매우 중요합니다. 상황에 알맞는 패키지를 사용할 수 있도록 노력하는 것이 중요합니다.

## Day 6 - React Native Layout System

리액트 네이티브에서는 flex를 사용하여 전체적인 구성을 정의합니다. 웹에서 사용하던 grid와 같은 스타일은 사용할 수 없습니다. 일단 간단하게 박스를 생성 해보겠습니다.

```jsx
import { StatusBar } from "expo-status-bar";

export default function App() {
  return (

      <View
        style={{ width: 200, height: 200, backgroundColor: "tomato" }}
      ></View>
      <View
        style={{ width: 200, height: 200, backgroundColor: "orange" }}
      ></View>
    </View>
  );
}

const styles = StyleSheet.create({});
```

![스크린샷 2022-06-06 오전 1.24.13.png](/images/posts/react-native-basic/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2022-06-06_%E1%84%8B%E1%85%A9%E1%84%8C%E1%85%A5%E1%86%AB_1.24.13.png)

코드를 위와 같이 수정하면 위에 사진처럼 상자가 생성됩니다.

생성된 상자를 보면 기본적으로 세로로 배열되는 것을 볼 수 있습니다. 그러면 상자 배열을 가로로 바꿔보겠습니다. 배열을 가로로 하기 위해선 상자 컴포넌트보다 상위 컴포넌트에 flexDirection을 ‘row’로 설정해줘야 합니다.

```jsx
import { StatusBar } from "expo-status-bar";
import { StyleSheet, Text, View } from "react-native";

export default function App() {
  return (
    <View style={{ flexDirection: "row" }}>
      <View style={{ width: 200, height: 200, backgroundColor: "teal" }}></View>
      <View
        style={{ width: 200, height: 200, backgroundColor: "tomato" }}
      ></View>
      <View
        style={{ width: 200, height: 200, backgroundColor: "orange" }}
      ></View>
    </View>
  );
}

const styles = StyleSheet.create({});
```

![스크린샷 2022-06-06 오전 1.27.56.png](/images/posts/react-native-basic/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2022-06-06_%E1%84%8B%E1%85%A9%E1%84%8C%E1%85%A5%E1%86%AB_1.27.56.png)

flexDirection을 ‘row’로 설정하면 가로로 배열되는 것을 볼 수 있습니다. ‘row’말고도 다양한 옵션이 있기 때문에 찾아보는 것을 추천합니다.

위에 코드를 보면 상자의 크기를 픽셀단위로 지정하였습니다. 그러나 이렇게 픽셀 단위로 상자의 크기를 지정하면 디바이스 종류마다 다른 화면을 보이게 됩니다. 따라서 픽셀로 상자의 절대값을 지정해주는 것 보다 flex를 사용하여 상자의 상대값을 지정해주는 것이 좋습니다. 아니 그냥 상대값을 사용하세요.

상대값을 사용하여 상자의 크기를 지정할 수 있는 flex를 사용하여 구성 화면을 구성해보도록 하겠습니다. 간단한 예시로 화면을 1대 1대 1로 나눠 보겠습니다.

```jsx
import { StatusBar } from "expo-status-bar";
import { StyleSheet, Text, View } from "react-native";

export default function App() {
  return (
    <View style={{ flex: 1 }}>
      <View style={{ flex: 1, backgroundColor: "teal" }}></View>
      <View style={{ flex: 1, backgroundColor: "tomato" }}></View>
      <View style={{ flex: 1, backgroundColor: "orange" }}></View>
    </View>
  );
}

const styles = StyleSheet.create({});
```

위 코드를 보면 상자를 감싸고 있는 View에 flex값을 1로 부여해주고 안에 상자에 각각 flex값 1을 부여해주고 있습니다. 우선 상위 컴포넌트에 flex값을 부여해주는 이유는 상위 컴포넌트가 공간을 가지고 있어야 하위 컴포넌트가 공간을 가질 수 있는데 만약 flex값을 지정해주지 않는다면 하위 컴포넌트가 가질 수 있는 공간이 정의 되지 않은 것이기 때문입니다. 따라서 상위 컴포넌트에서 flex값을 지정해주는 것이 중요합니다.

하위 컴포넌트에서 flex값을 1:1:1로 부여했을 때 3등분이 된 것을 볼 수 있습니다. 그렇다면 가운데 있는 상자의 flex값을 2로 변경해보도록 하겠습니다.

![스크린샷 2022-06-06 오전 1.39.10.png](/images/posts/react-native-basic/%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2022-06-06_%E1%84%8B%E1%85%A9%E1%84%8C%E1%85%A5%E1%86%AB_1.39.10.png)

위 사진처럼 가운데 박스의 영역이 더 커진것을 볼 수 있습니다. flex는 같은 선상에 존재하는 박스들에 정의된 flex값의 비율만큼 각 박스마다 공간을 가지게 됩니다.

앱에서 유저의 위치를 사용하기 위해선 사용자에게 먼저 위치 정보 사용 동의를 받아야 합니다. 사용자의 동의 여부와 위치 정보를 관리하기 위해 React의 useState, useEffect를 사용해야 합니다.

cf) useState

useState는 자바스크립트 라이브러리인 리액트의 Hooks 중 하나로 변수의 상태를 관리할 때 사용합니다. 자바스크립트에서는 const로 선언한 변수는 변경이 불가능 하지만 useState를 사용하면 const로 선언하여도 변수를 수정할 수 있습니다. useState의 사용 방법은 다음과 같습니다.

```jsx
import React, {useState} form "react";

const [변수명, 변수를수정하는함수명] = useState(초기값);
```

간단한 예시로 변수를 선언하고 변수를 수정해보겠습니다.

```jsx
import React, {useState} form "react";

const [food, setFood] = useState('apple');

console.log(food); //apple이 출력됨

setFood('melon') //setFood 함수로 food 변수의 값을 melon으로 변경
console.log(food); // melon이 출력됨
```

코드를 설명해보자면 우선 react에서 useState를 사져와야 합니다. 그 다음 const로 변수와 변수를 수정하는 함수를 useState를 사용하여 정의해줍니다. 변수의 기본값이 apple로 되어있기 때문에 변수를 수정하기 전에는 food라는 변수 안에 apple이 있습니다. 그러나 setFood라는 함수로 food 변수를 수정해주면 food라는 변수 안에는 melon아리는 값이 존재하게 됩니다.

cf) useEffect

useEffect는 리액트에서 컴포넌트가 렌더링 될 때 특정 함수를 실행시키는 리액트 Hook입니다. useEffect의 구조는 다음과 같습니다.

```jsx
useEffect(실행 시킬 함수, 배열)
```

실행 시킬 함수는 useEffect가 조건에 부합하면 실행 할 함수입니다. 배열은 useEffect가 함수를 시행시킬지 말지를 결정하는 중요한 부분입니다. 배열을 사용하여 useEffect를 총 3가지 상태로 정의할 수 있습니다.

1. 배열이 없는 경우

   ```jsx
   useEffect;
   ```

   useEffect안에 함수만 존재하고 배열이 없는 경우에는 렌더링(화면에 바뀔때)될 때 마다 함수가 실행됩니다.

2. 배열이 있으나 비어있는 경우

   ```jsx
   useEffect(함수, []);
   ```

   배열이 있지만 비어 있는 경우에는 처음 랜더링 될때만 실행됩니다.

3. 배열 안에 변수가 있는 경우

   ```jsx
   useEffect(함수, [변수]);
   ```

   배열 안에 변수가 있는 경우 변수가 변경될 때 마다 함수가 실행됩니다.

ex)

```jsx
function sayHello() {
  console.log("Hello world");
}
let say = false;
useEffect(sayHello); //앱 화면이 변경될 때 마다 sayHello 함수 실행
useEffect(sayHello, []); //앱 화면이 처음 실행될 때 한번 실행
useEffect(sayHello, [say]); //say 변수가 변경되면 sayHello함수 실행
```

앱에서 리액트의 useState와 useEffect를 사용하기 위해 리액트에서 useState, useEffect를 불러오겠습니다.

```jsx
import { StatusBar } from "expo-status-bar";
import { StyleSheet, Text, View, ScrollView, Dimensions } from "react-native";
import * as Location from "expo-location";
import React, { useState, useEffect } from "react";
```

사용자의 위치 정보를 가져오기 위해 사용자에게 위치 정보 접근 권한을 받고 위치 정보를 저장할 변수가 필요합니다.

```jsx
const getWeather = async () => {
  const { granted } = await Location.requestForegroundPermissionsAsync();
  if (!granted) {
    setOk(false);
  }
  const {
    coords: { latitude, longitude },
  } = await Location.getCurrentPositionAsync({ accuracy: 5 });
  const location = await Location.reverseGeocodeAsync(
    { latitude, longitude },
    { useGoogleMaps: false }
  );
  setCity(location[0].city);
  const response = await fetch(
    `https://api.openweathermap.org/data/2.5/onecall?lat=${latitude}&lon=${longitude}&exclude=alerts&appid=${API_KEY}&units=metric`
  );
  const json = await response.json();
  console.log(json);
};
useEffect(() => {
  getWeather();
}, []);
```

코드를 위와 같이 변경합니다. 코드에 대한 설명을 하자면 우선 response라는 변수에 fetch함수를 사용하여 해당 링크에 접속하여 데이터를 받아옵니다. (fetch 함수는 링크에 접속하여 데이터를 가져옴) response라는 변수에 데이터가 저장되면 우리는 데이터를 활용하ㅇ기 위해 json 형태로 변형 시켜야 합니다. 따라서 아까 저장한 response 변수 뒤에 .json()을 붙여 json형태의 데이터로 변형시킨 후 json이라는 변수에 변형한 데이터를 저장합니다. 마지마긍로 결과를 보기 위해 콘솔에 해당 데이터를 출력합니다. await를 사용한 이유는 앞서 언급했다시피 데이터를 가져오는데 시간이 소요되므로 데이터를 가져오기 전까지 코드를 실행하지 않고 대기하기 위해 사용하였습니다. (async는 getWeahter 함수에서 이미 선언하였기 때문에 다시 선언할 필요 없습니다. )

이제 저장한 데이터를 앱에서 보여주기 위한 설정을 해야합니다. 그런데 만약 데이터를 불러오고 있는 중에는 어떤 화면을 보여줘야할까요? 데이터를 불러오고 있는 중이라면 우리는 데이터가 없기 때문에 아무 화면도 보여주지 못합니다. 이러한 상황에는 원에 링이 돌고 있는 로딩중 애니메이션을 보여주면 좋습니다. 이러한 애니메이션을 추가하기 위해선 React Native에서 컴포넌트를 하나 가져와야합니다. 아래 링크로 들어가 어떤 컴포넌트인지 확인해보겠습니다.

[https://reactnative.dev/docs/activityindicator](https://reactnative.dev/docs/activityindicator)

웹사이트로 들어가면 ActivityIndicator로 만들어진 로딩중 애니메이션을 볼 수 있습니다. 우리는 이 컴포넌트를 사용해보겠습니다.

cf) 삼항 연산자

기존에 우리는 조건 문을 사용해서 참이면 실행하고 거짓이면 실행하지 않는 코드를 작성하였습니다. 그러나 항상 함수 안에 조건문을 넣어서 사용하는건 귀찮고 코드가 쓸데 없이 길어집니다. 이러한 불편한 점을 해결하기 위해 삼항 연산자가 탄생하였습니다. 삼항 연산자는 조건과 참일 때 실행할 코드, 거짓일 때 실행할 코드만 작성하면 됩니다. 삼항 연산자는 다음과 같이 사용합니다.

```jsx
조건 ? 참일때 실행 할 코드 : 거짓일 때 실행할 코드
```

ex)

```jsx
const apple = true;
apple ? console.log("Apple is true") : console.log("apple is flase");
//결과적으로 Apple is ture 출력
```

days 변수에 날씨 데이터가 없으면 로딩중인 애니메이션을 보여주는 코드로 변경해보겠습니다. 우선 가짜 데이터로 만들어 둔 날씨 창을 삭제하고 코드를 다음과 같이 수정합니다.

cf) .map 함수

.map 함수는 배열 뒤에 붙어 배열의 변수를 하나씩 받아 설정된 함수를 실행시키는 함수 입니다. .map 함수는 다음과 같이 사용함니다.

```jsx
const fruits = ["apple", "melon", "cherry", "mango"];

fruits.map((fru, index) => console.log(fru, index));
```

위 코드를 실행시키면 fruits에 저장된 변수가 index 번호와 함께 출력되는 것을 볼 수 있습니다. 이렇게 .map 함수는 배열에 담긴 변수를 하나씩 불러와 map 가로 안에 지정된 함수를 실행시킵니다. 우리는 이 함수를 여러개의 컴포넌트를 생성할 때 사용할겁니다.

ex)

```jsx
const fruits = ["apple", "melon", "cherry", "mango"];

fruits.map((fru, index) => <h1>{fru}</h1>);
```

위 코드는 furits 배열 안에 있는 변수의 개수만큼 h1 태그를 만들고 그 안에 변수를 넣는 코드입니다.

배열 안에 저장한 날씨 데이터를 보여주기 위해 삼항 연산자와 .map 함수를 사용하여 코드를 작성해보겠습니다.

### 7-6 제작한 앱 Expo 밖에서 사용할 수 있도록 export 하기

우리가 힘들게 제작한 앱을 컴퓨터를 키고 프로젝트를 실행해야만 앱을 사용할 수 있으면 좀 허무할 것 같아 앱을 우리 핸드폰에서 사용할 수 있도록 Export 해보겠습니다. 그러나 앱을 빌드하여도 안드로이드만 가능하고 iOS에서는 앱 빌드와 실제 디바이스에서 사용은 애플 개발자 계정(연간 129,000원)이 필요합니다. 따라서 아래 나오는 방법은 안드로이드만을 위한 방법입니다. 그래도 우리가 가지고 있는 탭에서 사용 가능하니 한 번 따라해보세요.

우선 프로젝트 터미널에서 아래 명령어를 입력합니다.

```jsx
expo build:android
```

위 명령어를 입력하면 expo에 로그인 하라고 터미널에 뜰 수 있습니다. 만약 로그인을 하라고 뜬다면 expo에 가입한 계정으로 로그인 하세요. 로그인이 완료되면 모두 기본 상태에서 엔터를 눌러 선택해줍니다.

브라우저에서 expo에 로그인이 되어 있지 않다면 로그인 해줍니다.

![Untitled](/images/posts/react-native-basic/Untitled%2027.png)

이렇게 빌드가 끝나면 다운로드 버튼이 생기게 됩니다. 다운로드 버튼을 눌러 앱 파일을 다운로드 해줍니다. 컴퓨터에서 파일을 다운 받은 후 핸드폰이나 탭으로 파일을 전송해도 되지만 번거로움을 줄이기 위해 만약 핸드폰이나 탬에 앱을 설치할거라면 핸드폰이나 탭에서 expo사이트에 접속한 뒤 파일을 다운 받는 것을 추천합니다.

핸드폰에서 해당 파일을 실행시켜 앱을 다운 받으면 됩니다.
